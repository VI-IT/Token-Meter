# Token Meter by VI-IT 1.0.9

## English

Fixes missing or wrongly assigned local LIVE activity when several ChatGPT workspaces share the same e-mail address.

- Adds a dedicated local LIVE row directly below the central ChatGPT button
- Shows the real number of currently active local Codex chats independently of account-card visibility
- Stops assigning all desktop activity to the first linked workspace with the same e-mail address
- Prevents active local sessions from disappearing inside a depleted or collapsed account
- Keeps per-account quota and server-reported token totals separate from PC-local chat activity
- Shows local token consumption in red and flashes when the value changes
- Keeps the exact turn lifecycle: LIVE starts with the Codex turn and ends on completion
- Updates the English and German screenshots to the current interface
- Preserves all existing accounts, authentication profiles, settings and quota history during the update

## Deutsch

Behebt fehlende oder falsch zugeordnete lokale LIVE-Aktivität, wenn mehrere ChatGPT-Arbeitsbereiche dieselbe E-Mail-Adresse verwenden.

- Fügt direkt unter dem zentralen ChatGPT-Knopf eine eigene lokale LIVE-Zeile ein
- Zeigt die echte Zahl aktuell laufender lokaler Codex-Chats unabhängig von der Sichtbarkeit einzelner Kontokarten
- Ordnet Desktop-Aktivität nicht mehr blind dem ersten verknüpften Arbeitsbereich mit gleicher E-Mail-Adresse zu
- Verhindert, dass aktive lokale Sitzungen in einem verbrauchten oder eingeklappten Konto verschwinden
- Hält kontobezogenes Kontingent und serverseitige Tokenstände getrennt von der PC-lokalen Chataktivität
- Zeigt lokalen Tokenverbrauch rot und lässt die Zahl bei Änderungen kurz aufleuchten
- Behält den echten Turn-Zustand bei: LIVE beginnt mit dem Codex-Turn und endet erst beim Abschluss
- Aktualisiert die englischen und deutschen Screenshots auf die aktuelle Oberfläche
- Behält beim Update alle bestehenden Konten, Anmeldeprofile, Einstellungen und den Kontingentverlauf bei
