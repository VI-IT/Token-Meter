# Token Meter by VI-IT 1.0.0

## English

First public Windows release of Token Meter by VI-IT.

- Multiple separately authenticated ChatGPT/OpenAI accounts
- Codex weekly quota, remaining percentage and exact reset time
- Account token totals and red consumption changes, including newly detected account activity from another device
- Live active-chat count for Codex activity detected on the current PC
- Dynamic account ranking and collapsible depleted accounts
- Exact one-time warning on the 11% → 10% transition
- German/English automatic Windows-language selection
- Central launcher for the existing ChatGPT desktop app
- Local account aliases and compact account management menu
- Ko-fi and PayPal support buttons with recognizable service icons in the About window
- Silent automatic updates for future GitHub releases

## Deutsch

Erste öffentliche Windows-Version von Token Meter by VI-IT.

- Mehrere getrennt angemeldete ChatGPT-/OpenAI-Konten
- Codex-Wochenkontingent, verbleibender Prozentwert und genaue Reset-Zeit
- Kontobezogene Tokenstände und rote Verbrauchsänderungen, einschließlich neu erkannter Kontoaktivität eines anderen Geräts
- Live-Anzahl der auf diesem PC erkannten aktiven Codex-Chats
- Dynamische Kontosortierung und einklappbare verbrauchte Konten
- Exakt einmalige Warnung beim Übergang von 11 % auf 10 %
- Automatische deutsche oder englische Windows-Oberfläche
- Zentraler Startknopf für die vorhandene ChatGPT-Desktop-App
- Lokale Kontonamen und kompaktes Kontomenü
- Ko-fi- und PayPal-Unterstützungsknöpfe mit erkennbaren Dienstsymbolen im Info-Fenster
- Stille automatische Updates für zukünftige GitHub-Releases
