# Support / Hilfe

## English

For installation problems, quota display issues or feature requests:

- Open a [GitHub issue](https://github.com/VI-IT/Token-Meter/issues) without private account data
- Email [info@vi-it.de](mailto:info@vi-it.de)
- Visit [www.vi-it.de](https://www.vi-it.de)

Please include the Token Meter version, Windows version, display language and a screenshot with all account names, email addresses and tokens removed.

If Token Meter is useful to you, you can voluntarily [say thanks via Ko-fi](https://ko-fi.com/viitde) or [support development via PayPal](https://paypal.me/viitde).

## Deutsch

Bei Installationsproblemen, fehlerhaften Kontingentanzeigen oder Funktionswünschen:

- Erstelle ein [GitHub-Issue](https://github.com/VI-IT/Token-Meter/issues) ohne private Kontodaten
- Schreibe an [info@vi-it.de](mailto:info@vi-it.de)
- Besuche [www.vi-it.de](https://www.vi-it.de)

Gib bitte die Token-Meter-Version, Windows-Version und Anzeigesprache an. Entferne aus Screenshots sämtliche Kontonamen, E-Mail-Adressen und Token.

Wenn dir Token Meter hilft, kannst du freiwillig [über Ko-fi Danke sagen](https://ko-fi.com/viitde) oder die [Entwicklung mit PayPal unterstützen](https://paypal.me/viitde).
